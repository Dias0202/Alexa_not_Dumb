# Release 0.1.1 — 2026-08-02

## Escopo

Correção operacional para concluir a implantação Alexa-hosted sem depender do painel S3 que apresentou falha no console.

## Conteúdo entregue

- Carregamento de `lambda/config/llm.json` antes do objeto S3 quando o arquivo local privado existe.
- Teste automatizado da prioridade da configuração local.
- Modelo de interação compilado e Lambda Alexa-hosted implantada em `us-west-2`.
- Teste remoto manual de `LaunchRequest` com status `SUCCESSFUL`.

## Limitações da release

- O teste de conversa por voz no simulador e em Echo físico continua pendente.
- A configuração ativa está no repositório privado Alexa-hosted como contingência. Ela não foi enviada ao GitHub, mas deve ser migrada para S3 quando o painel estiver disponível; após a migração, as chaves devem ser rotacionadas.
- A gratuidade depende da permanência dentro das cotas dos serviços externos. Não há garantia de custo zero fora dessas cotas.
