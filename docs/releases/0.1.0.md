# Release 0.1.0 — 2026-08-02

## Escopo

Primeira versão implementável da skill Alexa-hosted descrita no PDD e SDD: conversa em pt-BR, sessão curta, fallback de inferência e opção de inferência local autenticada.

## Conteúdo entregue

- Modelo de interação com carrier phrase e elicitação de `AMAZON.SearchQuery`.
- Backend Python com configuração S3, limite interno de seis segundos, três provedores e normalização de voz.
- Proxy FastAPI opcional para o Ollama, limitado a loopback e protegido por Bearer token.
- Testes locais e documentação de implantação/validação.

## Limitações da release

- Não inclui contas, chaves, provisionamento do Alexa Developer Console ou deploy remoto.
- Não valida o modelo no console ou em Echo físico.
- Não oferece memória entre sessões, streaming, automação de dispositivos ou RAG.
- Os modelos e limites dos provedores devem ser confirmados antes do uso, pois podem mudar.
